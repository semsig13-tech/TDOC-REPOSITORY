# Назначение
Логическая защита шин применяется в качестве быстродействующей защиты для отключения КЗ на шинах 6(10) кВ.
# Перечень уставок

| Защита | Обозначение<br>параметра,<br>ед.изм. |        Описание параметра         |              Диапазон               | Шаг  | По умолчанию |
| :----: | :----------------------------------: | :-------------------------------: | :---------------------------------: | :--: | :----------: |
|   ЛЗ   |                  -                   |           Режим работы            |        Введена/<br>Выведена         |  -   |   Выведена   |
|        |                  -                   |         Защищаемый объект         |      Т/СШ/<br>Двунаправленный       |  -   |      Т       |
|        |                  -                   |          Режим пуска ЛЗ           |               КЗ/МТЗ3               |  --  |      КЗ      |
|        |            $T_{БЛЛЗ}$, мс            |   Задержка блокирующего сигнала   |                5-100                |  5   |      50      |
|        |            $Т_{СРЛЗ}$, с             |        Время срабатывания         |                0-100                | 0,01 |      0       |
|        |                  -                   | Тип контроля направления мощности | Прямое/Обратное/<br>Двунаправленное |  -   |    Прямое    |
|        |                  -                   |           Режим без ОЛ            |        Введена/<br>Выведена         |  -   |   Выведена   |

Настройка «Режим пуска ЛЗ» позволяет выбрать по пуску какой из защит запускается ЛЗ. При выборе настройки «КЗ» ЛЗ запускается при пуске любой ступени МТЗ и ДЗ, при выборе «МТЗ 3» - только при пуске МТЗ 3, которая должна быть введена.
Настройка «Тип контроля направления мощности» позволяет выбрать при каком направлении мощности элемент вводится в работу.
Режим без ОЛ позволяет реализовать логическую защиту трансформатора в РУ без выключателя в цепи силового трансформатора. В этом случае срабатывает ЛЗШ, логика работы представлена на рисунке

# Функциональная схема
На рисунке [[Логическая защита шин (ЛЗШ)#^KZ-na-shinah|Рис. 1]] показана работа ЛЗШ в случае КЗ в шинах второй секции. В этом случае происходит следующая последовательность действий:
- ток КЗ протекает к точке КЗ;
- на ОВ и РВ секции 1 и на РВ секции 2 пускается МТЗ и ЛЗШ;
- РВ секции 2 посылает блокирующий сигнал по МДВВ РВ секции 1, который ретранслирует этот блокирующий сигнал по LAN в ОВ секции 1;
- авария ликвидируется РВ секции 2.

- авария ликвидируется ОЛ секции 2.

# Условия срабатывания и возврата

Срабатывание логической защиты происходит при:
- Наличии сигнала о пуске защит (МТЗ или ДЗ)
- Отсутствии блокирующего сигнала
